## ros2_hybrid_astar_nav2

Hybrid A* global path planner written in Python for **ROS 2 Humble**, designed for RViz2 visualization and Nav2-style workflows.

This folder is intentionally **self-contained** so it can be uploaded to GitHub as-is.

### Nav2 prerequisite (WSL / Ubuntu 22.04)

This project expects Nav2 packages to be installed if you want the Nav2 bringup launch to work:

```bash
sudo apt update
sudo apt install ros-humble-nav2-bringup
```
